1. Lab Architecture & Resource Sizing

The SOC home lab consists of two virtual machines operating within an isolated VirtualBox NAT Network. This enables secure traffic routing between the SIEM manager and the endpoint while exposing the web dashboard to the host browser.

Role / VM Name Operating System Allocated RAM vCPUs Network IP (DHCP)
Wazuh SIEM Server Ubuntu Server 22.04 LTS 2.5 GB – 3 GB 2 CPUs 192.168.100.10 (Example)
Monitored Endpoint Kali Linux (amd64) 1.5 GB – 2 GB 1 CPU 192.168.100.20 (Example)
Host System Windows 10 / 11 Remaining (~2 GB) Host Host Browser: https://<WAZUH_IP>
Low-RAM Optimization: Wazuh utilizes OpenSearch for indexing. On systems with 6–8 GB total RAM, a 2 GB swapfile on the Ubuntu server and setting JVM heap to -Xms512m -Xmx1g prevents memory exhaustion.

2. VirtualBox Network Configuration

  1. Open VirtualBox → File → Tools → Network Manager → NAT Networks.
  2. Ensure the NAT Network named SOCNet (CIDR: 192.168.100.0/24, DHCP: Enabled) is present.
  3. For both the Wazuh Server VM and the Kali Linux VM:
    • Right-click VM → Settings → Network → Adapter 1.
    • Set Attached to: NAT Network.
    • Set Name: SOCNet.

3. Deploying Wazuh SIEM Server (Ubuntu VM)

Boot the Ubuntu 22.04 VM and run these commands in the terminal (zero Python required):

Step 3.1: Configure Swapfile (Memory Buffer)

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

Step 3.2: Run Official All-In-One Automated Installer

curl -sO https://packages.wazuh.com/4.9/wazuh-install.sh
sudo bash ./wazuh-install.sh -a
Important: When the installer finishes, it displays the web dashboard URL, username (admin), and a unique password. Record these credentials immediately!

Step 3.3: Adjust Indexer Memory Heap

sudo sed -i 's/-Xms1g/-Xms512m/g' /etc/wazuh-indexer/jvm.options
sudo sed -i 's/-Xmx1g/-Xmx1g/g' /etc/wazuh-indexer/jvm.options
sudo systemctl restart wazuh-indexer

4. Enrolling the Kali Linux Monitored Endpoint

Step 4.1: Run the Automated Agent Setup Script

Boot your Kali Linux VM and execute the installer script included in the repository:

sudo bash scripts/install-agent.sh <WAZUH_SERVER_IP>

Or perform manual enrollment:

curl -s https://packages.wazuh.com/key/GPG-KEY-WAZUH | gpg --no-default-keyring --keyring gnupg-ring:/usr/share/keyrings/wazuh.gpg --import
chmod 644 /usr/share/keyrings/wazuh.gpg
echo "deb [signed-by=/usr/share/keyrings/wazuh.gpg] https://packages.wazuh.com/4.x/apt/ stable main" | sudo tee -a /etc/apt/sources.list.d/wazuh.list
sudo apt-get update -y
sudo WAZUH_MANAGER="<WAZUH_SERVER_IP>" apt-get install -y wazuh-agent
sudo systemctl daemon-reload && sudo systemctl enable --now wazuh-agent

Step 4.2: Enable Auditd Kernel Telemetry

Deploy the custom audit rules to track command execution (execve) and authentication tampering:

sudo cp configs/audit.rules /etc/audit/rules.d/wazuh-soc.rules
sudo augenrules --load
sudo systemctl restart auditd

Step 4.3: Verify Enrollment

Open your host browser at https://<WAZUH_SERVER_IP>, log in as admin, and navigate to Server Management → Endpoints Summary. Your Kali VM will show status: Active.

6. How to Push the Project to GitHub

The repository at C:\Users\Sidharth\wazuh-soc-lab is already structured, documented, and staged with all files.

Step 6.1: Set Your Git Identity (PowerShell on Host)

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

Step 6.2: Create the Initial Commit

cd C:\Users\Sidharth\wazuh-soc-lab
git commit -m "feat: complete Wazuh SOC home lab setup, configs, and attack simulations"

Step 6.3: Create an Empty Repository on GitHub

  1. Log into your GitHub account in your web browser.
  2. Go to https://github.com/new.
  3. Set Repository name to: wazuh-soc-lab.
  4. Choose Public (recommended for cybersecurity portfolios).
  5. Uncheck "Add a README file", "Add .gitignore", and "Choose a license" (the local project already has all three!).
  6. Click Create repository.

Step 6.4: Link Remote & Push

git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/wazuh-soc-lab.git
git push -u origin main
Authentication Tip: When prompted by GitHub for credentials, enter your GitHub username and use a Personal Access Token (PAT) (generated in GitHub Settings → Developer settings → Personal access tokens) as your password.
